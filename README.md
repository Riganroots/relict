# Relict

Denim clothing brand website, starting with bootcut jeans and other fits.

Website: https://riganroots.github.io/relict/

## Source

`dist/index.html` is a self-contained responsive website. No dependencies or build step are required. Open it in a browser, or serve `dist` with a static web server.

Includes fit filters, preferred waist selection, a device-local shopping bag, and copyable product enquiries.

## Before opening orders

The homepage and denim gallery include supplied photos. Replace the remaining illustrative product cards with confirmed product listings. Confirm product names, prices, measurements, stock, contact information, shipping and returns policies. Checkout, payment processing and order storage are not connected.

## Deployment

The public website is hosted on GitHub Pages at https://riganroots.github.io/relict/.

GitHub Pages publishes the root of the `gh-pages` branch. The editable source is in `main` under `dist/`. To publish an update, synchronize the contents of `dist/` to the root of `gh-pages`, preserving `.nojekyll`. Updates to `main` alone do not automatically publish.

The earlier ChatGPT Sites copy remains separate.
