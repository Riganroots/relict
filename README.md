# Relict

Denim clothing brand website, starting with bootcut jeans and other fits.

Website: https://relict-denim.sochiktm2.chatgpt.site

## Source

`dist/index.html` is a self-contained responsive website. No dependencies or build step are required. Open it in a browser, or serve `dist` with a static web server.

Includes fit filters, preferred waist selection, a device-local shopping bag, and copyable product enquiries.

## Before opening orders

Replace concept illustrations with real product photos. Confirm product names, prices, measurements, stock, contact information, shipping and returns policies. Checkout, payment processing and order storage are not connected.

## Deployment

The existing website is hosted with ChatGPT Sites and currently has private access. This GitHub repository stores the website source. GitHub commits do not automatically deploy to the existing Sites address; publication is managed separately through Sites.
